Flujo recomendado
  1. Descarga una carpeta.
  2. Revísala desde Explorador.
  3. Crea subcarpetas de trabajo si las necesitas.
  4. Selecciona imágenes y agrégalas al Catálogo.
  5. Usa el catálogo para preparar los productos que se publicarán en Sorprezz.
Sincronización: si agregas, mueves o eliminas archivos manualmente desde Windows, usa “Sincronizar biblioteca” o “Reindexar” para actualizar conteos y vistas.
